# 双色球投注方案生成Excel工具

## 📋 项目简介

一个完全自动化的双色球投注方案生成Excel工具，通过VBA宏实现智能号码分析、投注方案生成和中奖判断功能。

## 🎯 核心功能

- ✅ **智能24码分析** - 基于最近30期数据自动计算热门号码区间
- ✅ **自动方案生成** - 使用模板A/B自动生成符合结构要求的投注号码
- ✅ **中奖自动判断** - 一键比对开奖号码并记录中奖情况
- ✅ **历史记录管理** - 完整保存投注和中奖历史
- ✅ **数据统计分析** - 多维度统计中奖率、ROI、号码热度等
- 🆕 **号码推算功能** - Python脚本自动推算下期参考号码
- 🔥 **V9.0终极系统** - 动态聚焦+29组覆盖+三引擎矩阵的复合策略

## 📦 文件说明


## 🚀 快速开始

### 1. 打开Excel文件

使用 `双色球投注方案生成工具_VBA版.xlsx` 并启用宏

### 2. 导入VBA代码

1. 按 `Alt + F11` 打开VBA编辑器
2. 插入新模块
3. 复制 `lottery_vba_code.txt` 中的代码
4. 粘贴到模块并保存

### 3. 输入数据

在【1-数据输入】表输入最近30期开奖数据

### 4. 生成方案

运行【生成投注方案】宏（Alt+F8）

### 5. 判断中奖

输入开奖号码后运行【判断中奖】宏

## 🎮 VBA宏功能

### 生成投注方案

- 基于24码自动生成8-12注投注号码
- 80%使用模板A（3奇3偶）
- 20%使用模板B（2奇4偶）
- 智能验证连号、同尾等结构要求

### 判断中奖

- 自动比对投注方案与开奖号码
- 计算中红球数和蓝球匹配情况
- 自动判定中奖等级并记录奖金

## 📖 投注模板

### 模板A（80%使用频率）
- 奇偶比：3奇 + 3偶
- 大小比：3小（1-16）+ 3大（17-33）
- 连号：≤1组
- 同尾：≤1组

### 模板B（20%使用频率）
- 奇偶比：2奇 + 4偶
- 大小比：2小 + 4大
- 连号：≤1组
- 同尾：≤2组
